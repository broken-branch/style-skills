# HTML style: Google HTML/CSS Style Guide (condensed)

Use this skill only when the user explicitly requests Google's HTML/CSS Style Guide. It replaces the house `html-style` skill for this task.

Follow [references/rules.md](references/rules.md) when writing or reviewing HTML. Read the relevant topic sections before editing; each rule names and links its original section. Cite the guide and section when explaining a review finding.

Scope: the shared General rules and HTML sections of Google’s HTML/CSS Style Guide at commit `577f395c` (2026-10-23). The companion language is covered by its separate skill.

Preserve the source's optional choices and exceptions, including optional tag omission, validity exceptions, and availability-qualified media advice. This guide does not establish an accessibility conformance target or replace separate project requirements.

When a rule conflicts with a formatter or linter the project already runs, the project's tooling wins. State that conflict in one line.

The bundled rules work offline. If an ambiguity requires an unavailable original section, state that limitation and use the project's existing convention for that point.
