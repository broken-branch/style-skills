# Original worked examples

Source tag: `[GOOGLE-HTMLCSS]` — Google HTML/CSS Style Guide.

These are independent document conventions: reading-list omits permitted tags throughout; search-form retains explicit tags. The latter illustrates markup for a GET /search endpoint, which a consuming application must provide. IDs connect labels to controls and all contain a hyphen.

- [Native controls and necessary IDs](examples/search-form.html)
