# Licensing and source provenance

House prose and original worked examples are under CC BY 4.0. Tools, tests, and configurations are MIT. Each source skill carries its own license and attribution. A reference to another work does not change the house license; source sentences and examples from restricted or share-alike works are not included in the house skills.

The design house skill follows this split: original prose/examples are CC BY 4.0,
and its filtered token configuration is MIT with a bundled `TOKENS-LICENSE`.
Its [source inventory](skills/design-style/references/sources.md) records the
visual influences and provisional house decisions. Company source terms remain
unverified; no company skill, source card, font asset or logo is included.

- **Effective Rust:** the site's footer links a CC BY-NC-ND 4.0 license badge. The skill remains link-only and includes no book text. [Original site](https://effective-rust.com/).
- **GitLab SQL:** the page has a CC BY-SA 4.0 content badge, the site footer reserves all rights, and the repository's MIT grant names GitLab's software. The prose license remains unresolved, so the skill stays link-only. [Guide](https://handbook.gitlab.com/handbook/enterprise-data/platform/sql-style-guide/), [repository license](https://gitlab.com/gitlab-com/content-sites/handbook/-/raw/main/LICENSE).
- **C++ Core Guidelines:** the custom license permits personal or internal business use. No guideline text is bundled. [License](https://github.com/isocpp/CppCoreGuidelines/blob/master/LICENSE).
- **CUBE CSS:** no open license was found for the content; the author's issue tracker says it is not open source. The skill points to the original only. [Author's issue tracker](https://github.com/piccalil-li/cube-css-issue-tracker).
- **ShellCheck wiki and WCAG:** diagnostic IDs, criterion numbers, and links accompany independently worded house rules. No wiki or WCAG text is included, and no W3C copied-material notice is claimed.
- **MDN:** the CSS source skill uses CC BY-SA 4.0 under MDN's permission to use version 2.5 or later. House citations name the actual works and remain references only. [MDN licensing](https://developer.mozilla.org/en-US/docs/MDN/Writing_guidelines/Attrib_copyright_license).
- **PEP 8 and PEP 257:** the original documents state public-domain dedications. Each skill's independently restated prose also has a CC0 1.0 Universal fallback; this does not relicense the PEPs.

License reviews inspect raw HTML as well as visible page text, including license links and image alternative text. A repository's software license is not assumed to cover separately published prose. Copyright notices, requested author credits, and source-specific limitations are retained in the relevant source skill.
