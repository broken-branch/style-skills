# Original worked examples

Source tag: `[MDN-CSS]` — MDN CSS code style.

Apply panel to a note and result-list to a container whose children form a grid. Properties are grouped by purpose. The panel uses modern rgb(), a full six-digit border color, and double-quoted strings. Layout overrides accumulate at 40rem and 60rem; fractional viewport widths leave no gap.
